# vn — Вʼєтнам FAQ

Односторінковий FAQ українською про поїздку до Вʼєтнаму. [Astro](https://astro.build), статичний HTML, мінімум JS. Спершу верстається під мобільний.

Живе тут: https://eleutherius.github.io/vn/

```bash
pnpm install
pnpm dev         # http://localhost:4321/vn/
pnpm build       # статика в dist/
pnpm check       # перевірка типів
```

## Як додати питання

Кожен файл `src/content/faq/*.md` — це окремий розділ. Кожен заголовок `##` у ньому — окреме питання, а текст під ним до наступного `##` — відповідь.

```md
---
title: Візи та вʼїзд          # необовʼязково, інакше береться "# Заголовок" або імʼя файлу
description: Е-віза, строки…  # підзаголовок розділу
icon: 🛂
slug: vizy                    # якір /#vizy
updated: 2026-10-08
---

## Чи потрібна віза?

Так. **Markdown** працює повністю: списки, таблиці, [посилання](https://…).

## Як оформити е-візу? {#e-visa}

`{#e-visa}` задає власний якір питання. Без нього якір — транслітерація заголовка.

> [!TIP]
> Блоки: `[!TIP]`, `[!NOTE]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]`.
```

- Розділи сортуються за `order`, а без нього — за іменем файлу (`01-…`, `02-…`).
- Файли, що починаються з `_`, ігноруються. Шаблон із поясненнями: [`_template.md`](src/content/faq/_template.md).
- `draft: true` ховає розділ.
- Текст до першого `##` показується як вступ до розділу.

Назва сайту, підказки для пошуку, дисклеймер і посилання на репозиторій задаються в [`src/site.config.ts`](src/site.config.ts).

## Пошук

Пошук повністю клієнтський і працює без сервера та індексу. Він:

- не зважає на регістр, апостроф (ʼ ’ '), ґ/г, діакритику (phở = pho);
- спрощено відкидає закінчення: «візу» знайде «віза», «е-візою»;
- для кирилиці пробує латиницю: «телеграм» знайде Telegram, «граб» знайде Grab;
- підсвічує збіги й розгортає відповіді, якщо їх ≤ 3;
- зберігає запит в URL (`?q=віза`), тож пошуком можна поділитися.

## Структура

```
src/content/faq/*.md      контент
src/content.config.ts     схема frontmatter
src/lib/faq.ts            розбір md → розділи/питання (marked)
src/pages/index.astro     сторінка + JSON-LD FAQPage
src/scripts/faq.ts        пошук, scrollspy, якорі, «поділитися»
src/styles/global.css     дизайн-токени, світла/темна тема
```

## Деплой

Кожен пуш у `main` запускає [GitHub Actions](.github/workflows/deploy.yml): `pnpm install` → `pnpm check` → `pnpm build`, після чого `dist/` публікується на GitHub Pages. Запустити деплой вручну можна з вкладки Actions (`workflow_dispatch`).

- Версія pnpm зафіксована в `packageManager` у `package.json`, CI бере її звідти.
- Сайт живе в під-шляху `/vn`, тому в `astro.config.mjs` задано `base: '/vn'`. Для власного домену приберіть `base` і змініть `site`.
